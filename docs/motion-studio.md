# Motion Studio

Moved out of `CLAUDE.md` on 4 Nov 2026; the text below is unchanged. `CLAUDE.md` keeps a one-line pointer to this file.

The MOTION STUDIO tab in the side panel is a second conversation, with the **Motion Director** (`motion.mjs`, `/api/motion`, thread `data/motion.json`). It runs Claude Code on **Opus 5.5 at extra-high effort, always and only for motion** (`claude-opus-5-5`, `xhigh`), with one tool server, `connectors/motion-studio` (read its `README.md`). The Director writes a composition that paints every frame from `t`; Playwright drives this PC's Chrome to capture each frame and ffmpeg stitches them; the score is synthesised in the same page on the same beat grid. Every draft is scanned frame by frame for dead stretches, hard colour cuts and off-beat cuts; `motion_final` is refused only while a draft breaks one of those rules. There is no per-frame score gate (removed 26 Oct 2026): the critic (`critic.mjs`, Opus 5.5) runs only when a draft passes `critic: true`, which the Director does only when Wesley asks. The Director stops after at most two drafts a turn. House rules the engine enforces: real spring physics (`M.spring`), no CSS transitions/keyframes/fake bounce, the score synthesised on the beat grid, with recorded sounds only from the licensed library (`sfx.mjs`, 4 Nov 2026: Openverse, CC0 / public domain / CC BY only, files on D: in `output/sfx/`, placed with `S.sample`, CC BY credits written to `credits.txt`; no audio file in the page), cuts on the beat, no dead frames, frame 0 held. Colour-scheme changes must be crafted transitions (a ground change inside two frames fails), and the theme binds, not the content. The kit carries three.js r185 and GSAP 3.14.2 (SplitText, DrawSVG, MorphSVG), pinned in package.json and copied into every project: GSAP only as a paused timeline seeked in `render(t)`, three.js only rendered inside `render(t)`, springs still required. The Director and the critic both work from Disney's twelve principles translated into springs and film time. Series briefs live in `connectors/motion-studio/series/<name>/BRIEF.md` with `series.json` (The Art of Operations; The Operator's Ledger, the Monday episodes). **Narration is the one audio exception:** only a series whose `series.json` has `"narration": true` (the Ledger) may carry it, made with `motion_narrate` (Wesley's VoxCPM2 clone from VoiceStudio, de-plosived, word-timed with Whisper; a stand-in voice is allowed for drafts and refused for a final), placed with `voice: [{ line, at }]`, mixed and ducked by the engine, loudness finished to the series target, and a captions `.srt` written with the final. **Style library (2 Nov 2026):** when no series brief sets the look, the Director reads the Brain note `styles-03-12-location-and-evidence` (index `40-Marketing/motion-library/motion-library.md`). It picks the style by content from its "which style for which content" table, applies that style's WRW build, and says which style it chose. Add a new style there, not in code. Change the craft brief in `motion.mjs`, the rubric in `connectors/motion-studio/critic.mjs`, the brand in `motion.md`.
