# Episodes

Every Operators' Ledger episode lives here, one folder each: `ep01-unit-economics`, `ep02-…`.
Shared things (brand, characters, voice, DESIGN.md) stay one level up and are used by every episode.

**ep01-unit-economics is still at `../ep01-unit-economics`.** It was open in a live HyperFrames preview when this folder was tidied, so it was not moved. Move it into this folder once the preview is closed: `Move-Item ..\ep01-unit-economics .`, then check that `episode-01-brief.md` still points at `../../DESIGN.md` (it points at `../DESIGN.md` today).
